##  Nota sobre a Persistência de Dados
> **Aviso:** Conforme a especificação para esta entrega acadêmica, a persistência via banco de dados relacional (**SQLAlchemy + SQLite**) foi desativada. O projeto está operando **100% em memória principal** utilizando estruturas nativas do Python (`list` e `dict`).

> *Os códigos referentes ao banco de dados foram mantidos comentados nos arquivos para fins de histórico de desenvolvimento.*
